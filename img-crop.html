How to crop an image

  1. Upload an image. Drag and drop a file onto the upload area, or click Select image file. JPG, PNG, WEBP, and GIF are supported.
  2. Select the crop area. Click and drag over the image preview to draw a rectangle around the part you want to keep.
  3. Crop the image. Click Crop Image to extract the selected area.
  4. Download. Click Download cropped image to save the result to your device.

Frequently asked questions

Is this image cropper free?
Yes. The tool is completely free to use with no hidden limits.
Are my files uploaded to a server?
No. The image is read and cropped locally using the HTML Canvas API. Nothing is sent to a server.
Can I choose the exact crop area?
Yes. Simply click and drag on the image preview to draw a custom rectangle for your crop.
Does cropping change the image format?
No. The output keeps the same file format as the input image.
Do you offer Cash on Delivery?
This is a digital tool, so Cash on Delivery does not apply. The tool is free to use online.
