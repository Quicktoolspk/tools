How to merge PDF files

  1. Add your PDF files. Drag and drop files onto the upload area, or click Select PDF files. You can add multiple files at once.
  2. Reorder if needed. Drag the files in the list to arrange them in the order you want them to appear in the final document.
  3. Remove any unwanted files. Click the red × on any file to remove it from the list.
  4. Merge and download. Click Merge PDF files, review the stats, then click Download merged PDF.

Key features

Merge multiple PDFs

Add as many PDF files as you need. Pages are combined in the order you arrange them.

Drag-to-reorder

Drag any file in the list to change its position. The merged output respects the order you set.

Runs in your browser

The PDFs are read and combined locally with pdf-lib. Nothing is uploaded to a server.

Standard PDF output

The merged file is a standard PDF that opens in any PDF reader on desktop, tablet, or mobile.

Why merge PDF files

  • One tidy document. Combine invoices, contracts, scans, or reports into a single file.
  • Easier sharing. A single PDF is simpler to email or attach than several separate files.
  • Consistent ordering. Control the exact page order before sharing, printing, or archiving.
  • No quality loss. Pages are copied into the new PDF without re-encoding, so images and text stay the same.

Frequently asked questions

Is this PDF merger free?
Yes. The tool is free to use and does not require an account or login.
Are my PDFs uploaded to a server?
No. The PDFs are read and combined locally with pdf-lib. Nothing is sent to a server.
Can I reorder files before merging?
Yes. Drag any file in the selected files list to change its position. The merged output uses the order shown in the list.
Is there a limit on how many files I can merge?
There is no fixed number limit, but very large totals (many files or very large files) may be slow on low-memory devices. Keeping the total size under 100 MB is recommended.
Does merging reduce quality?
No. Pages are copied into the new PDF without re-encoding, so text and images stay the same.
Does the merged file open in any PDF reader?
Yes. The output is a standard PDF produced by pdf-lib and opens in any modern PDF reader.
