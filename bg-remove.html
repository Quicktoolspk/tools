How to remove a background

  1. Upload an image. Drag and drop a file onto the upload area, or click Select image file.
  2. Pick the background color. Use the color picker to select the exact color of the background you want to remove.
  3. Adjust the tolerance. Move the slider until the background is gone but your subject remains intact.
  4. Download. Click Remove Background, then download the result as a transparent PNG.

Frequently asked questions

Is this background remover free?
Yes. The tool is completely free to use with no hidden limits.
Are my files uploaded to a server?
No. The image is processed locally using the HTML Canvas API. Nothing is sent to a server.
How does it work?
This tool uses a Chroma Key technique. It reads every pixel, compares it to the color you selected, and makes it transparent if the difference is within your tolerance level.
Does it work on complex backgrounds?
This tool works best on solid, uniform backgrounds (like a white studio backdrop or a green screen). It will not work well on busy or gradient backgrounds.
